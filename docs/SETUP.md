# Project setup and reproducibility

This guide regenerates all derived analyses, LaTeX tables, and figures from
the raw data already present in the repository. Downloading ISTAT data is not
part of the standard run: the versioned Italian dataset is the reproducible
input to the analysis.

## Prerequisites

- Python 3.13;
- `make`;
- Internet access only for the first run, to install Python dependencies.

On Fedora:

```bash
sudo dnf install python3.13 make
```

## One-command setup and run

From the repository root:

```bash
make all
```

This command creates the `.venv/` virtual environment if needed, installs the
versions pinned in `requirements.txt`, runs the complete pipeline, and checks
that essential outputs exist.

The environment uses Python 3.13 and these dependencies:

- `matplotlib==3.11.1`;
- `scipy==1.18.0`;
- `pymannkendall==1.4.3`.

## Available commands

```bash
make setup       # creates .venv and installs dependencies
make reproduce   # regenerates all derived outputs
make all         # setup + reproduce; recommended command
make check       # checks imports and Python syntax
```

To use the environment interpreter manually:

```bash
source .venv/bin/activate
python --version
```

## What is regenerated

The pipeline, defined in `src/scripts/run_pipeline.py`, runs the following in
order:

1. conversion and aggregation of the US SSA `yobYYYY.txt` files;
2. US and Italian diversity metrics and the ISTAT coverage check;
3. Mann--Kendall and Wilcoxon tests, plus the US--Italy comparison;
4. spike and decline detection, name overlap, and convergence;
5. a geographic robustness check using SSA state-level data;
6. figures `fig2`--`fig8` in `docs/paper/figures/`;
7. LaTeX tables in `docs/paper/tables_tex/`.

PNG figures, the Matplotlib cache, `.venv/`, and the large intermediate US CSV
`dataset/processed/us_names_long.csv` are ignored by Git. They are
regenerable artifacts, not versioned data.

## Explicit ISTAT data refresh

Do not run this as part of routine reproduction. It queries an undocumented
online ISTAT service and can change the underlying dataset:

```bash
.venv/bin/python src/scripts/00_scrape_istat_contanomi.py
```

If it is run, review and document the changes to
`dataset/istat/istat_contanomi_full.csv`, then regenerate the complete
pipeline with `make all`.

## PDF in VS Code

The VS Code LaTeX extension is an interface and still requires a LaTeX
distribution installed on the system. Once it is installed and configured,
open `docs/paper/bozza_paper.tex`; the figures generated by the pipeline are
in the directory expected by the manuscript. PDF compilation is not included
in `make all`, because it depends on the locally selected LaTeX distribution.
